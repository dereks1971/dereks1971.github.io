THU pipeline
The production tool behind The Hour Unveiled, a teaching channel on YouTube.

What it does
THU pipeline is a private tool used by one person, the owner of The Hour Unveiled, to produce the channel's videos. When a finished video file or a large production file is ready, the tool uploads it to a folder in the owner's own Google Drive, so it reaches the owner's computer through Google Drive for desktop.

What it can access
It asks Google for one permission only: drive.file, which lets it see and change only the files and folders that this tool itself created in the owner's Drive. It cannot see, read or change any other file in the Drive.

Who can use it
Nobody else. The tool is not offered to the public, has no user accounts and no sign up.
