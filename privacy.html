Privacy policy

THU pipeline · effective October 20, 2026

Who this covers

THU pipeline is a private production tool used only by the owner of The Hour Unveiled, a YouTube channel. It has no other users. This policy describes what the tool does with Google user data.

Google data it accesses

With the owner's consent, the tool uses the Google Drive permission drive.file. That permission covers only the files and folders the tool itself creates. The tool uses it to create a folder for the channel's production files, upload finished files into it, and read back each uploaded file's name, size and checksum to confirm the upload is complete and undamaged.

It does not read, list, change or delete any other file in the owner's Drive. It does not access email, contacts, calendars or any other Google service.

How the data is used

Only to deliver the owner's own production files to the owner's own Drive. The data is not sold, shared, used for advertising, or used to train any model. No one other than the owner receives it.

How the data is stored

The sign-in token Google issues is kept privately by the owner, in the owner's own storage, and is never published. The uploaded files stay in the owner's Google Drive under the owner's control.

Removing access

The owner can withdraw the tool's access at any time at myaccount.google.com/permissions. Files already uploaded stay in Drive until the owner deletes them.

Google API Services User Data Policy

THU pipeline's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be sent through The Hour Unveiled's YouTube channel.
